# The First 90 Days

Thirty-six role-playing scenarios of what the child welfare system puts a parent
through — a knock at the door, an assessment that rates what it cannot see, clocks
that do not wait. Built from published Pennsylvania court opinions, composited so
no real family is recognizable.

**Play it:** https://vexxdz911.github.io/first-90-days/

- Foundation 7 · Hard 13 · Complex 16 — 1,048 scenes, 117 endings
- Two editions of every scenario: a comic edition (graphic-novel skin, synthesized
  sound off by default, and a Watch Mode that plays itself with random choices so
  a room can watch) and a plain edition
- A strategy guide for every scenario — the winnable route, walked through the
  scenario's own choice graph and verified before publication here
- Every deadline in these stories is real law, cited in each scenario's debrief

**Prototype.** General information, not legal advice. Pending attorney
verification and a compensated lived-experience review before any organizational
or parent-facing program use.

Design and sources: `design.md`, `visual-bible.md`, `audio-bible.md`,
`sources-and-alterations.md`, `sources-batch-A.md` … `sources-batch-E.md`.
Part of the Tactic Watch project.
